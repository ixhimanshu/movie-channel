# Movie Channel

A personal 24/7 live TV channel that plays movies from `media/Movies` in random order,
watchable in any IPTV app (TiviMate, IPTV Smarters, VLC, Kodi...) with a TV guide.

Powered by [ErsatzTV](https://ersatztv.org) (installed at `/Applications/ErsatzTV-Legacy.app`).

## Server deployment (no Mac needed)

The channel runs on the Easypanel server (`server.augaan.com`) as the **movie-channel**
Compose service inside the **morpedia** project.

| What | URL |
|---|---|
| Web player (with movie counter) | <https://tv.augaan.com> |
| IPTV playlist (M3U) | `https://tv.augaan.com/iptv/channels.m3u` |
| TV guide (EPG) | `https://tv.augaan.com/iptv/xmltv.xml` |
| ErsatzTV admin (password) | <https://tv-admin.augaan.com>, login in `deploy/admin-credentials.txt` |
| Add a movie by link (password) | <https://tv-admin.augaan.com/submit/> |
| View/delete server movies (password) | <https://tv-admin.augaan.com/submit/movies/> |

Works from anywhere, not only home Wi-Fi.

How it's built ([deploy/](deploy/)):

- Easypanel deploys from GitHub: movie-channel → Source → Git uses
  <https://github.com/ixhimanshu/movie-channel> (public), branch `main`, compose file
  `deploy/docker-compose.yml`. That file is generated by `deploy/build-compose.sh`, which
  embeds `web/index.html`, `deploy/nginx.conf` and the submitter
  files as base64, so the compose file is self-contained.
- **ersatztv**: `ghcr.io/ersatztv/legacy`, config and movies on Docker volumes
  (`etv-config`, `media` → `/media/Movies`). Software x264 at 720p (no GPU on the VPS).
- **player**: nginx. Port 80 serves the player and proxies `/iptv/` to ErsatzTV.
  Port 8080 is the full admin UI behind basic auth.
- The starter-film fetcher is no longer deployed, so restarting or redeploying does
  not download intentionally deleted starter movies again. `deploy/fetch-movies.sh`
  remains available for an optional manual bootstrap of a new media volume.
- **submitter**: the "add a movie by link" page (`deploy/submitter.py`, served at
  `/submit/` on the admin domain). Submitted links download directly without a license
  check. Videos from Internet Archive or yt-dlp-supported sites download at up
  to 720p into `/media/incoming`, then move to `/media/Movies/<Title>/`. The submission list
  is kept in `/media/.submit/jobs.json`. yt-dlp is reinstalled on every start, so if
  YouTube downloads start failing, restart the service.
  **Manage Movies** (`/submit/movies/`) lists completed video files on the server,
  with search and file sizes. Delete asks for confirmation, permanently removes the
  selected movie folder (or video file). Completed downloads and deletions automatically
  scan the library, wait for scan completion, empty missing-file records, reset the
  channel to a fresh shuffle, and stop the old streaming session so playback reconnects
  to the new schedule. This restarts the current movie; buffered video may remain briefly.
  Channel progress and failures appear on Manage Movies. **Reshuffle channel** can
  refresh an existing stale schedule or retry a failed update. Pending updates survive
  restarts. The submitter reads the mounted SQLite database to verify scan/build
  completion; all changes to ErsatzTV go through its API.
- Domains (Easypanel → movie-channel → Domains): `tv.augaan.com` → `player:80`,
  `tv-admin.augaan.com` → `player:8080`. DNS is Cloudflare (proxied CNAMEs to
  `server.augaan.com`). The server only accepts web traffic via Cloudflare, so the
  default `*.easypanel.host` domain does not work.
- ErsatzTV scans the library every hour (Settings → Scanner), so new files in
  `/media/Movies` join the channel on their own.

**To deploy a change:** edit the file, run `deploy/build-compose.sh`, commit and
`git push`, then click **Deploy** in Easypanel → movie-channel (or let the GitHub webhook
do it, if one is set up). Always run the build script before committing: the server only
sees `deploy/docker-compose.yml`, not the source files.

**To change the admin password:** delete `deploy/admin-credentials.txt`, run
`deploy/build-compose.sh` (makes a new one), then commit, push and deploy as above.
`admin-credentials.txt` is git-ignored; only the password's hash is in the repo.

## Watch in a browser (Mac version)

Open **<http://192.168.1.92:8410>** on any computer, phone or tablet on your Wi-Fi.
It shows the movie title, an exact counter (`35:14 / 1:22:59`), minutes left, a
progress bar and what's next. Keys: `f` fullscreen, `m` mute, `i` hide/show the counter.

The counter is exact: the stream stamps every segment with its broadcast time
(`EXT-X-PROGRAM-DATE-TIME`), and the page compares that with the movie's start time
from the guide. The player lives in [web/](web/) (`server.js` serves it).

## Watch it on your TV

Your TV and this Mac must be on the same Wi-Fi.

1. In your IPTV app choose **Add playlist → M3U URL** and enter:
   `http://192.168.1.92:8409/iptv/channels.m3u`
2. If it asks for an **EPG / TV guide URL**, enter:
   `http://192.168.1.92:8409/iptv/xmltv.xml`
3. Open **Movie Channel**. You join whatever is playing, mid-movie, like real TV.

`192.168.1.92` is this Mac's current address. Run `scripts/status.sh` to print the
current URLs. To stop it changing, set a DHCP reservation for this Mac in your router.

## Adding movies

`media/Movies` is a shortcut to `/Users/Shared/MovieChannel/Movies`. The real files live
there because macOS blocks background apps from reading `~/Documents` until you click
an "Allow" prompt. Point ErsatzTV at anything outside Documents/Desktop/Downloads.

1. Make a folder per movie: `media/Movies/Title (Year)/Title (Year).mp4`
   (mkv/avi/mp4 all work; the `Title (Year)` naming gives the guide clean titles).
2. Run `scripts/rescan.sh`.

New movies join the shuffle and appear in the guide. Only add files you have the right
to use. The starter set is public-domain films from the Internet Archive.

## How it's configured

| Piece | Setting |
|---|---|
| Library | ErsatzTV *Movies* local library → `/Users/Shared/MovieChannel/Movies` |
| Collection | Smart collection **All Movies** (`type:movie`), so new files are included automatically |
| Schedule | **Movie Shuffle 24/7**: All Movies, *Shuffle* order, *Flood* (back-to-back, never ends) |
| Channel | **1 – Movie Channel**, group *My Channels*, logo from `branding/logo.png` |
| Streaming | *Next* engine, HLS Segmenter |
| FFmpeg profile | 1280×720 H.264 via Apple VideoToolbox (hardware), AAC stereo, loudness normalized |

Transcoding only runs while someone is watching (On Demand), so the Mac is idle otherwise.

## Keeping it on 24/7

- The Mac must be awake. `scripts/start.sh` uses `caffeinate` to prevent sleep while it runs.
  For permanent use, also set **System Settings → Energy → Prevent automatic sleeping when the display is off**.
- To start ErsatzTV at login: **System Settings → General → Login Items → +** → `ErsatzTV-Legacy`.
- Watching away from home: install [Tailscale](https://tailscale.com) on the Mac and your
  phone/TV device, then use the Mac's Tailscale IP in the URLs above.

## Files

```
media/Movies/      your movies, one folder each (shortcut to /Users/Shared/MovieChannel/Movies)
branding/          channel logo (logo.svg source, logo.png uploaded)
scripts/           start / status / rescan helpers, etv-api.sh (API calls), fetch.sh (resumable download)
downloads/         ErsatzTV installer .dmg (safe to delete)
```

ErsatzTV's own data (database, settings) lives in `~/Library/Application Support/ersatztv`.
